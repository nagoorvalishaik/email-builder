What’s supported?

HTML href, image src, background, and link alias attributes. Images and backgrounds that share the same URL are flagged as duplicates. Empty link aliases are filled in lowercase with up to 3 words of the link text. Links styled as CTA buttons (a class containing “cta” on the link, inside it, or on one of its four nearest parent elements, so table-based buttons are caught) use 2 words plus _cta instead (filler words like “and”, “the”, “to” skipped), or the first 3 words of the image file name for image links. Repeated aliases are numbered in order: name, name1, name2. Mailto, tel, # and SFMC system links (profile center, view online) are not auto-filled, but get an optional alias you can apply. Unsubscribe links always get the alias “unsubscribe” (never _cta) and can be switched to RedirectTo(@urlOrganic); view-online links can be switched to view_email_url. Outlook VML buttons and backgrounds (v:roundrect, v:fill) and inline CSS url() backgrounds are kept in sync with the matching link or background. Background url() inside <style> blocks is not included. The opencounter and usermatch tracking tags are added before </body> if missing. CSS url(), srcset, and links inside AMPscript code blocks are not included. Values retain their original HTML entities.
